# RS Strategy - Live Signal Generation & EOD Data Fetching

This directory contains the RS (Relative Strength) Strategy implementation with live signal generation and daily EOD data fetching capabilities.

## Files Overview

### Core Files
- `rs_backtester_core.py` - Main backtesting engine for RS strategy
- `api.py` - FastAPI endpoints for RS strategy
- `database.py` - Database models and utilities
- `setup_database.py` - Database setup script

### New Files Added

#### 1. `rs_live_signal_generator.py`
**Purpose**: Generates live BUY/SELL signals using RS strategy logic

**Key Features**:
- Uses the same RS calculation logic as the backtester
- Fetches data from `nifty500_data_with_metadata.sqlite`
- Stores signals in `rs_live` table
- Supports quality filters (price, volume, turnover)
- Parallel processing for better performance
- Comprehensive logging

**Usage**:
```python
from rs_live_signal_generator import RSLiveSignalGenerator

# Initialize generator
generator = RSLiveSignalGenerator()

# Generate signals
result = generator.generate_signals(config_id=1)

# Get latest signals
signals = generator.get_latest_signals(days_back=7)
```

#### 2. `rs_eod_data_fetcher.py`
**Purpose**: Fetches daily End-of-Day data for Nifty 500 stocks and Nifty 50 index

**Key Features**:
- Fetches data using yfinance API
- Stores data in `stock_data` and `index_data` tables
- Parallel processing for faster data fetching
- Rate limiting to avoid API restrictions
- Historical and daily data fetching
- Data cleanup and maintenance

**Usage**:
```python
from rs_eod_data_fetcher import RSEODDataFetcher

# Initialize fetcher
fetcher = RSEODDataFetcher()

# Fetch daily data
result = fetcher.fetch_daily_data(days_back=1)

# Fetch historical data
result = fetcher.fetch_historical_data(days_back=365)

# Get data summary
summary = fetcher.get_data_summary()
```

#### 3. `test_rs_setup.py`
**Purpose**: Test script to verify the setup and functionality

**Usage**:
```bash
python test_rs_setup.py
```

## Database Schema

### New Table: `rs_live`
Stores live trading signals generated by the RS strategy.

| Column | Type | Description |
|--------|------|-------------|
| id | INTEGER | Primary key |
| signal_date | DATE | Date of the signal |
| symbol | TEXT | Stock symbol |
| action | TEXT | BUY, SELL, or HOLD |
| rs_score | REAL | Relative strength score |
| rs_rank | INTEGER | Rank based on RS score |
| price | REAL | Stock price at signal time |
| reason | TEXT | Reason for the signal |
| config_id | INTEGER | Strategy configuration ID |
| created_at | TIMESTAMP | When the signal was created |

### Existing Tables
- `stock_data` - Nifty 500 stock price data
- `index_data` - Nifty 50 index data
- `strategy_config` - Strategy configurations
- `backtest_results` - Backtest results
- `trade_logs` - Trade execution logs
- `portfolio_snapshots` - Portfolio snapshots

## Configuration

### Strategy Configuration
The RS strategy uses the following key parameters (configurable via `strategy_config` table):

- `lookback_weeks` - Short-term RS calculation period (default: 5)
- `lookback_months` - Medium-term RS calculation period (default: 20)
- `lookback_quarters` - Long-term RS calculation period (default: 60)
- `max_positions` - Maximum number of positions (default: 20)
- `position_size_pct` - Position size as percentage (default: 5.0%)
- `stop_loss_pct` - Stop loss percentage (default: 15.0%)
- `min_turnover` - Minimum daily turnover filter (default: 1,000,000)
- `min_price` - Minimum price filter (default: 10.0)

### Data Sources
- **Stock Data**: Nifty 500 constituents via yfinance
- **Index Data**: Nifty 50 index (^NSEI) via yfinance
- **Database**: SQLite database at `nifty500_data_with_metadata.sqlite`

## Troubleshooting

### Common Issues

1. **Database Locked**: Run `python setup_database.py` to reset connections
2. **No Data**: Ensure data fetching is working with `rs_eod_data_fetcher.py`
3. **Import Errors**: Check Python path and dependencies
4. **API Rate Limits**: Reduce parallel workers in data fetcher
